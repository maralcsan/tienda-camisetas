# Tienda de Camisetas - "Programa tu estilo"

¡Bienvenido al proyecto de la **Tienda de Camisetas**! Este sitio web es una aplicación frontend desarrollada con HTML5, CSS3 y JavaScript vanilla, enfocada en ofrecer prendas con diseños temáticos para desarrolladores, estudiantes y entusiastas de la tecnología.

---

##  Características del Proyecto

* **Catálogo de Productos:** Exposición de playeras temáticas (Python, Git, Linux, Error 404, etc.) con imagen, descripción y precio.
* **Navegación Interna:** Menú con saltos directos a secciones clave mediante anclas (`#nos`, `#cont`).
* **Sección "Quiénes Somos":** Información sobre la marca y reproductor de video promocional (`<video>`).
* **Guía de Tallas:** Tabla interactiva/estructurada con dimensiones (Chica, Mediana, Grande).
* **Formulario de Pedidos:** Interfaz interactiva para solicitar pedidos (selección de talla, cantidad, fecha de entrega, correo y validación con JavaScript).
* **Contacto Directo:** Información de soporte y medios de comunicación.

---

##  Tecnologías Utilizadas

* **HTML5:** Estructuración semántica del contenido.
* **CSS3:** Estilos básicos integrados para la maquetación.

##  Cómo Ejecutar el Proyecto

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone git@github.com:maralcsan/tienda-camisetas.git
   ```
2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd tienda-camisetas
   ```
3. **Abrir la página web:**
   Haz doble clic en el archivo `index.html` o ábrelo directamente desde tu navegador web preferido.
